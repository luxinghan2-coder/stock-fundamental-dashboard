# AEL 股票基本面驾驶舱 V2.4.2

本版本修正技术分析中的“斐波那契”定义：

- `斐波纳契轴点`：使用最新一个已完成交易日的 H/L/C，计算 Pivot + Fibonacci Pivot，匹配参考行情软件的“轴点 / 经典 / 斐波纳契”表。
- `斐波那契回撤`：继续保留近 252 个交易日 swing high / swing low 的 0%、23.6%、38.2%、50%、61.8%、78.6%、100% 回撤。

二者不是同一算法，因此不再混用。

## 斐波纳契轴点公式

P = (H + L + C) / 3

R1 = P + 0.382 × (H-L)
R2 = P + 0.618 × (H-L)
R3 = P + 1.000 × (H-L)

S1 = P - 0.382 × (H-L)
S2 = P - 0.618 × (H-L)
S3 = P - 1.000 × (H-L)

经典轴点同时显示：
R1=2P-L，R2=P+(H-L)，R3=H+2(P-L)
S1=2P-H，S2=P-(H-L)，S3=L-2(H-P)
